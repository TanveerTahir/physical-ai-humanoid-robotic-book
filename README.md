# Physical AI & Humanoid Robotics Textbook

This repository contains a comprehensive AI-Native textbook on Physical AI & Humanoid Robotics using Docusaurus, deployed to GitHub Pages, and integrated with an AI-native learning system including RAG chatbot, personalization, Urdu translation, and Claude Code subagents.

## Overview

The Physical AI & Humanoid Robotics textbook is an educational platform that combines traditional textbook content with modern AI technologies to provide an interactive, personalized learning experience for students and professionals in robotics.

## Structure

The textbook is organized into 8 sections:
- Section A: Foundations
- Section B: ROS2 Nervous System
- Section C: Digital Twin Simulation
- Section D: NVIDIA Isaac Platform
- Section E: Vision-Language-Action
- Section F: Capstone Projects
- Section G: Engineering Notes
- Section H: Appendices

## Features

- Interactive RAG chatbot for content queries
- User authentication and personalization
- Urdu translation support
- Claude Code subagents for learning assistance
- GPU/Jetson deployment notes for each chapter
- Hands-on labs and mini projects
- URDF examples and simulation content

## Development Status

This project is under active development following a spec-driven approach:
- `/book` - Docusaurus documentation
- `/api` - FastAPI backend
- `/agents` - Claude Code subagents
